در زبان Go، این علامت‌ها که با `%` شروع می‌شوند، **Verb** (فعل) نامیده می‌شوند. این‌ها به پکیج `fmt` می‌گویند که داده را با چه فرمتی به رشته (String) تبدیل کند.

تفاوت اصلی `Printf` و `Sprintf`:
*   **`fmt.Printf`**: خروجی را مستقیماً در کنسول **چاپ می‌کند**.
*   **`fmt.Sprintf`**: خروجی را چاپ نمی‌کند، بلکه آن را به صورت یک **متغیر رشته‌ای (string) برمی‌گرداند** (مثل کدی که برای ساخت هدر Authorization استفاده کردیم).

در ادامه، پرکاربردترین Verbها را دسته‌بندی کرده‌ام:

### ۱. عمومی‌ترین Verbها (همه کاره)

*   **`%v` (Value):** مقدار متغیر را به فرمت پیش‌فرض خودش نمایش می‌دهد. بسیار منعطف است و برای اکثر مواقعی که نمی‌دانید دقیقاً چه فرمتی بدهید، عالی است.
*   **`%+v` (Struct with Fields):** اگر یک "استراکت" را با این فرمت چاپ کنید، **نام فیلدها** را هم در کنار مقدارشان نشان می‌دهد. (بسیار مفید برای دیباگ).
*   **`%#v` (Go Syntax):** مقدار را دقیقاً به شکلی که در کد Go نوشته می‌شود نشان می‌دهد (مثلاً نام پکیج و نوع استراکت را هم می‌آورد).
*   **`%T` (Type):** به جای مقدار، **نوع (Type)** متغیر را چاپ می‌کند (مثلاً می‌گوید این متغیر `int` است یا `string`).

### ۲. رشته‌ها (Strings)

*   **`%s`**: رشته یا اسلایس بایت (`[]byte`) را به صورت متن خام چاپ می‌کند.
*   **`%q` (Quoted):** رشته را داخل "کتیشن" قرار می‌دهد. اگر رشته شما کاراکترهای خاص داشته باشد، آن‌ها را به صورت Escape شده (مثل `\n`) نشان می‌دهد.

### ۳. اعداد (Numbers)

*   **`%d` (Decimal):** مخصوص اعداد صحیح (Integer) در مبنای $10$.
*   **`%f` (Float):** مخصوص اعداد اعشاری.
*   **`%.2f`**: عدد اعشاری را فقط تا $2$ رقم اعشار نشان می‌دهد (عدد $2$ قابل تغییر است).
*   **`%x` (Hex):** عدد یا رشته را به مبنای $16$ (هگزادسیمال) تبدیل می‌کند (مثلاً برای نمایش هش‌ها یا توکن‌ها).

### ۴. منطقی و آدرس (Boolean & Pointer)

*   **`%t` (True/False):** مخصوص متغیرهای `bool`.
*   **`%p` (Pointer):** آدرس حافظه متغیر را نشان می‌دهد (با `0x` شروع می‌شود).

---

### مثال کاربردی برای درک تفاوت‌ها:

```go
type User struct {
    ID   int
    Name string
}

u := User{ID: 1, Name: "Ali"}

fmt.Printf("%v\n", u)   // خروجی: {1 Ali}
fmt.Printf("%+v\n", u)  // خروجی: {ID:1 Name:Ali}
fmt.Printf("%#v\n", u)  // خروجی: main.User{ID:1, Name:"Ali"}
fmt.Printf("%T\n", u)   // خروجی: main.User

price := 12.5
fmt.Printf("Price: %.2f\n", price) // خروجی: Price: 12.50
```

### چه زمانی از کدام استفاده کنیم؟

1.  **برای ساخت URL یا هدر:** حتماً از **`Sprintf`** و معمولاً از **`%s`** یا **`%v`** استفاده کنید.
    *   `url := fmt.Sprintf("https://api.com/user/%d", userID)`
2.  **برای دیباگ سریع:** از **`%+v`** استفاده کنید تا بفهمید داخل استراکت چه خبر است.
3.  **برای چاپ خطاها:** از **`%v`** استفاده کنید تا متن خطا را بگیرید.

**نکته امنیتی:** هیچ‌وقت پسورد یا توکن‌های حساس را با `%#v` در لاگ‌ها چاپ نکنید، چون تمام جزئیات ساختار داده را فاش می‌کند. برای این کار `%s` یا ستاره‌گذاری دستی بهتر است.
